# 2026-09-07 影子 A/B：600池模型 前向对照协议

> 目的：离线 A/B（40 vs 600）收益随窗口翻转、不足以定夺。改用**真前向测试**：
> 两个模型在**同一个 599 截面上**每日打分、存逐日概率，2~4 周后用真实未来 5 日收益判定谁更能排序。
> 线上 model_v2 / 页面**完全不受影响**。

## 每日操作（收盘后，各 ~2~5 分钟）

```bash
python scripts/26_refresh_largepool.py     # 559 只大池今日日线增量补进 large_pool.db（40 只由 service 维护）
python scripts/27_shadow_ab.py --recent 700  # 打分+落库+出 summary（默认写 results/shadow_ab.db）
```

- 结果：`results/shadow_ab_summary.json`（per_model_full=含样本内(虚高) / per_model_oos=真正前向）。
- `scripts/27` 每次全量重算并 UPSERT：越往后跑，`>cutoff` 的前向日子越多、ret5 越完整。
- 可装 Windows 计划任务每天 ~15:40 自动跑 26→27。

## 关键口径（避免被假数字骗）

- **样本内虚高**：本次模型（40 与 600）都训练到 2026-09-07，故回测窗口 2023-11→09-07 **全在训练集内**——
  全窗口 RankIC（live40 0.054 / shadow600 0.379）**不可作判据**（shadow600 尤其像背题）。
- **判据只看 `>cutoff(2026-09-07)` 的前向日子**：从下一个交易日开始每日累积。
- 两模型始终在同一 599 池、同一特征下打分（`make_signals_all(data599)`），苹果对苹果。
