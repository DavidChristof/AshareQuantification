# 2026-09-10 新模块：实盘炒股（本金 ¥3000 · 模型给建议 · 人工下单后记账）

> 按「每次大改动在 docs/ 下留说明」约定。已合入 main。

## 需求

「在模拟炒股以外再加一个实盘炒股模块（由模型给出手动买卖股票的建议，本金设为 3000），
支持实盘决策（**着重考虑市场实时波动导致的成交成功与否**）。」

## 定位与边界（重要）

- **只给建议、绝不自动交易**：程序**没有**任何券商 API 对接，人工在券商 App 下单后回来记账。
  因此**不需要程序化交易报备**；与之前「模型成熟前不接程序化实盘」的决定不冲突
  （那条是「不让程序下单」，本条是「帮你想清楚并记账」）。
- **与现有两个账户完全隔离**：自动纸面盘 `paper/paper_account.db`、模拟炒股
  `paper/manual_account.db` 的代码路径一律未动；新增第三个 `paper/real_account.db`。
- 实盘账户**不**接入自动刷新 / 开盘自动调仓 / 影子 A/B（`scripts/05`、`updater`、
  `auto_open_execute`、`scripts/27` 都不知道它的存在）。

## ¥3000 的硬算术（必须在界面上讲清楚）

- 2 仓位 × 100 股/手 → 每股上限 ≈ `3000 / 2 / 100` = **¥14.2**
- 计入单笔最低佣金 ¥5 后，**可买价格带 ≈ ¥7 – ¥14**（回本涨幅 ≤1.5% 的地板 ≈ ¥6.9）
- 往返费用：¥14 一单 ≈ **0.8%**；¥3 低价股 ≈ **3.4%**（不经济 → 直接不建议）
- 结论：**建议常常只有 0–1 只** → 界面必须给出原因（价格带/费用/限额），而不是空表

## 成交可行性判定（本模块的核心）

`quant/trading/fill.py`（纯函数，无网络/无 FastAPI）：把「这单能不能成交」变成可计算、可穷举测试的判定。

| 状态 | 触发（严格档） |
|---|---|
| 🟢 `fillable` 可成交 | 委托价落在当日已触及区间内、盘口有量、现金/整手/时段都 OK |
| 🔵 `likely` 大概率 | 盘口一档量 < 建议股数（可能部分成交）、接近涨跌停（≤0.5%） |
| 🟠 `hard` 难成交 | **涨停封板（买不进，一字板卖一无挂单）/ 跌停封板（卖不出）**、委托价高于今日最高价、需改价 |
| ⚪ `missed` 已错过 | 现价较参考价漂移 > 2%（追价风险）/ 急跌接飞刀；**卖出**侧也用于「止损止盈触发价已过去」 |
| 🔴 `blocked` 不可下单 | 非交易时段 / 未开盘 / 停牌 / **T+1**（当日买入不可卖）/ 非整手 / 资金不足 |
| ⚫ `unknown` 无行情 | 池外股票无实时行情 → 提示「以券商 App 为准」，**不瞎判** |

设计要点：
- **封板优先于漂移**：涨停时价格漂移必然 >2%，若不特判会被误报成「已错过」→ 加 `limit_locked`
  让结论固定为「难成交（封板）」（这正是首轮测试抓出来的 bug）。
- 参考价 = 昨收（实时快照的 `prev_close` 优先），漂移判定与追高保护同口径。
- 给出**建议委托价**：买取卖一价、卖取买一价（tick 0.01 取整，不越涨跌停）。
- 给出**含费回本价**（不动点迭代，正确处理「最低佣金」这个非线性项）。

## 费用真实化

`quant/trading/paper.py` **增量**改动（默认 0 → 既有账户/测试逐值不变）：

## 边界与注意

- `avg_cost` **不含费用**（与手动盘一致）→ 界面单列「含费回本价」，避免误以为已回本。
- 「读时写」接口：`positions`/`advice` 会更新持仓最高价（移动止损用）并对齐净值快照，
  与手动盘同模式；**绝不写交易**。
- 实时行情：常驻池只有 40 只训练池 → 600 池候选按建议名单**批量抓取**并 **10 秒 TTL 缓存**
  （新浪限速）；抓不到就判 `unknown`。
- 止损/止盈对实盘**只提示不自动卖**（人工执行）；触发价已错过会被判 `missed` ——
  这正是实盘与纸面最大的差异。
- 若日后真要接入券商 API 自动下单：那是**另一件事**（需程序化交易报备 + 合规流程），
  本模块刻意不提供该能力。

## 价格口径（2026-09-11 补充：回答"建议委托价为什么=现价"）

**问**：建议委托价为什么和现价一样？明天开盘价不是会变吗？

**答**：买入的建议委托价取**卖一价**（保证能立刻成交）。**盘后五档盘口收敛**，卖一价就等于
最后一笔成交价（收盘价）→ 二者重合；盘中通常差 1 个最小变动（0.01）。
更关键的是：这个数是「**按当前盘口现在挂单的价**」——**快照，不是明日开盘价的预测**
（我们刻意不预测开盘）。所以盘后那条「可成交」判的是**今天**那一场，明天开盘一跳空就作废。

**改动**（本日）：
- 非交易时段下，每条建议额外给 `open_ref_price` = **今收 ×(1±open_premium_pct%)**（默认 0.5%，
  与开盘自动调仓 `_open_ref_prices` **同口径**）作为明日开盘价的近似，并置 `price_basis="last_session"`。
- 前端在「建议委托价」下方显示「开盘参考 ≈ ¥X」；盘后横幅明确写「判定依据的是上一交易日盘口」
  「开盘后按实时卖一/买一价刷新」。
- 盘中（9:30 后）仍用实时卖一/买一价，那才是可直接下单的数。

实测（09-11 00:21 盘后）：601600 快照价 9.92 → 开盘参考价 **9.97**（9.92×1.005）。

## 实盘费用闸门收紧 1.5% → 1.2%（2026-09-11，含证）

**背景**：用户问「模型的止损线是不是还是太激进了」。分两步回答。

### 第一步：止损线本身 —— 不用再放松（两轮复盘）

40 只模型池、6.1 万笔滚动建仓（持有≤20 日）：

| 规则 | 被扫出 | 均收益 | 止损后10日 |
|---|---|---|---|
| 旧 2.5×ATR + **盘中**触发 | 34.8% | 0.77% | **+1.25%**（= 被震出） |
| **现 3.0×ATR + 收盘触发** | 24.6% | **1.24%** | **−0.35%**（= 止损对了） |
| 3.5×ATR / 4.0×ATR + 收盘 | 22.1% / 20.8% | 1.24% / 1.24% | −0.43% / −0.49% |

- 「止损后10日」由 **+1.25% 翻成 −0.35%** —— 这是 09-08 校准奏效的直接证据（以前是震出、现在是切对了）。
- 再放松到 3.5×/4.0×ATR，**均收益一模一样**（1.24%）→ 放松无收益、只多扛风险。
- 真正起作用的是「**收盘触发**」而非倍数：同为 3.0×ATR，改回盘中触发就退回 30.1% 扫出率、止损后又变 +1.33%。
- 唯一仍偏紧的是高波动主板票（德业 ATR 4.6% → 止损被 ±10% 板幅压到 **2.17×ATR**）——这是**交易所封顶**，日线规则下无解。

### 第二步（更要紧）：真正的杀手是**费用**，不是止损

554 只「¥3000 买得起」的票、43 万笔机械化交易、按实盘费用口径（100 股 + 最低佣金 ¥5）：

| 规则 | 被扫出 | **毛**均收益 | **净**均收益 | 费用拖累 |
|---|---|---|---|---|
| 旧 2.5×ATR+盘中 | 33.4% | +0.60% | −1.21% | 1.81% |
| **现 3.0×ATR+收盘** | 23.3% | **+0.96%** | −0.86% | 1.82% |
| 3.5×ATR+收盘 | 20.4% | +0.95% | −0.87% | 1.82% |
| 不设止损 8×ATR | 16.1% | +0.94% | −0.88% | 1.82% |

- 现版**毛收益最高**，放松无益（与第一步一致）。
- **四种规则的费用拖累完全相同（1.81~1.82%）** —— 因为它是"一买一卖"的固定成本，**与止损宽窄无关**。
  平均每笔名义金额只有 **¥729**，往返 **¥10.38 = 1.42%**，几乎全是「最低佣金 ¥5」。
- 所以对 ¥3000 账户：**「这单够不够大」比「止损多宽」重要得多**。
  （注：这是**机械式**建仓的池子平均水平，代表**成本结构**，不是模型选股的真实表现。）

**改动**：`real.max_breakeven_pct: 1.5 → 1.2`（往返费用 ≤1.2% 才建议 → 约名义 ≥¥870，
即 1 手 ≥¥8.7 或 2 手 ≥¥4.35）。实测生效：可买价格带下限 **¥6.91 → ¥8.72**。
新增测试 `test_shipped_config_gate_filters_inefficient_orders` 锁定该口径（¥9.9 过、¥7.0 滤）。
