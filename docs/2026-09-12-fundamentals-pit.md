# 时点财务数据（PE/ROE）+ 修正④：PE 口径必须用不复权价

承接 [2026-09-11-pit-universe.md](2026-09-11-pit-universe.md)。那篇解决了「选股**宇宙**的幸存者偏差」，
这篇解决「选股**因子**能不能历史复现」——线上 `select_daily` 里 PE/ROE 占 60% 权重，
历史时点值此前拿不到，所以线上策略**一直无法严格回测**。现在拿到了，并且在校验中发现并修掉了一个口径错误。

## 1. 做了什么

### 1.1 下载季度财务数据（`scripts/38_fetch_fundamentals.py`）

| 项目 | 结果 |
|---|---|
| 数据源 | **同花顺** `stock_financial_abstract_ths`（主）/ 新浪 `stock_financial_abstract`（备） |
| 落库 | `data/fundamentals.db` → `financials` + `fetch_state` |
| 覆盖 | **2620 只 / 77,548 行 / 报告期 2019-03-31 ~ 2026-06-30** |
| 失败 | **0**（成功 2610，跳过 10 只无数据） |
| 耗时 | 66.5 分钟（`--workers 1 --min-gap 1.5`） |
| 字段 | `symbol, report_date, eps_diluted, eps_weighted, roe, roe_weighted, bps` |

**限速踩坑记录**（三换数据源）：新浪 `stock_financial_analysis_indicator`（~8 页/只）跑到 65/600 就被软封；
新浪 `stock_financial_abstract`（1 请求/只）即便降到 2.5 req/s 也在 ~100 只后被封；
**换到同花顺（不同 host）后 2610 只 0 失败**。结论：同一 host 的并发策略再保守也会被封，**换源比降速有效**。

### 1.2 时点化（`quant/data/fundamentals.py`）

原始数据有两个陷阱，直接用就是未来函数：

1. **数值是「年内累计」**：600519 在 2020 年是 Q1 11.04 → H1 19.05 → Q3 28.54 → 全年 39.42。
   算 TTM 必须先去累计（年内差分、跨年 Q1 重置）再滚动 4 期。
2. **报告期 ≠ 公告日**：2020-06-30 的半年报 8 月底才公告，7 月用它就是偷看未来。

处理方式：

- `disclosure_date()`：报告期 → **法定披露截止日**（Q1→04-30、H1→08-31、Q3→10-31、年报→次年 04-30）。
  用截止日而非实际公告日，是**保守**做法——只会晚用、绝不早用，**结构上不可能有未来函数**。
- `ttm_panel()`：对每个交易日 t 取 `avail_date <= t` 的**最新一期**，再往前 4 期求和。
  **绝不**先把整表 ffill 到每日再 shift（那会污染边界）。
- `load_raw_close()`（新增于 `quant/data/universe_pit.py`）：不复权价面板，见第 3 节。

## 2. 校验（`scripts/39_validate_fundamentals.py`）

「PE 中位数 25 倍」这种数字**好看不等于正确**——口径错的话中位数照样可能落在合理区间。
所以主检是**恒等式**，不是看分布。

### 2.1 主检：ROE 恒等式（跨字段交叉验证）

```
ROE = 净利润/净资产 = EPS/BPS
PE = 价/EPS，PB = 价/BPS   =>   ROE = PB/PE
```

`eps / bps / roe` 是同一条记录的三个独立字段，这个恒等式**不是数据源自带的**，而是三者之间的
代数约束。任何一方口径错（EPS 没去累计 / BPS 用了未来值 / ROE 单位是小数），恒等式就崩。

实测（`implied = 100*PB/PE` vs 报告 `roe_ttm`，2020–2026 共 20 个采样日）：

| 指标 | 结果 |
|---|---|
| 中位绝对误差 | **0.12 ~ 0.43 pp** |
| 落在 5pp 内占比 | **93.4% ~ 98.7%** |
| **Spearman** | **0.92 ~ 0.98** |

**结论：通过。** EPS 去累计、BPS、ROE 三者口径自洽。

> ⚠️ 看 Pearson 会得到 0 附近甚至负数。原因：误差最大的样本全是**资不抵债**的票
> （报告 ROE = −1941%、−1089%，此时 ROE 本身无意义），极端值把 Pearson 拖垮了。
> 这类数据要看 **Spearman**。（我自己先看了 Pearson，误判成"相关性崩塌"，是错的。）

### 2.2 分布（`2026-08-31` 为例）

| 指标 | p1 | p25 | p50 | p75 | p95 | p99 |
|---|---|---|---|---|---|---|
| PE | 4.09 | 15.4 | **26.9** | 55.2 | 219 | 1123 |
| TTM ROE (%) | −154 | 1.4 | **5.9** | 10.7 | 19.4 | 29.3 |
| PB | 0.31 | 1.38 | **2.35** | 4.41 | 13.6 | 42.8 |

均落在 A 股常识区间。PE 有值率 **77% ~ 81%**（其余为 TTM 亏损，PE 置 NaN —— 与线上 `MIN_PE` 行为一致，
**是设计如此，不是缺失**）。PE>1000 占 0.3%~1.6%、PE<1 占 0~0.05%，无异常堆积。

## 3. 修正④：PE 口径必须用**不复权价**（本次最重要的发现）

### 3.1 问题

`full_daily.close` 是 **qfq 前复权**，锚定在**今天**。也就是历史价已被「今天之后发生的所有
**送转与分红**」折算过；而财务数据里的 EPS 是 **as-reported**（报告期当时的股本口径，未经追溯重述）。
两者相除，历史 PE 会被系统性低估：

```
某票送转前真实：价 100，EPS 1.0  -> 真实 PE = 100
10送10 后，qfq 价已被折半
   => qfq价/EPS = 50/1.0 = 50          （低估一半）
```

### 3.2 实测失真量级

复现：`.venv/Scripts/python.exe scripts/39_validate_fundamentals.py`（E 段）

**E0 先验证不复权价本身可信**：`raw = amount / volume`。在锚定日 `2026-08-31`，
`qfq/raw` 比值 p50 = **1.01**、p1 = 0.97、p99 = 1.04 —— 确认 `amount/volume` 确实是元/股。

**E1 同一日两种口径的 PE 截面排序相关**（选股只看排序，所以排序相关才是关键指标）：

| 采样日 | p50(qfq/raw) | p5 | Spearman |
|---|---|---|---|
| 2020-04-30 | 0.874 | **0.366** | **0.9384** |
| 2022-12-30 | 0.937 | 0.543 | 0.9661 |
| 2024-12-31 | 0.960 | 0.703 | 0.9907 |
| 2026-08-31 | 1.005 | 0.992 | 0.9999 |

**E2 按「该日之后是否发生过送转」分层**：

| 采样日 | 分层 | n | p50 比 | p5 | Spearman |
|---|---|---|---|---|---|
| 2020-04-30 | 日后有送转 | 337 | 0.738 | **0.235** | **0.8616** |
| 2020-04-30 | 无送转 | 1609 | 0.883 | 0.455 | 0.9611 |
| 2023-08-31 | 日后有送转 | 251 | 0.952 | 0.486 | 0.9566 |
| 2023-08-31 | 无送转 | 1838 | 0.954 | 0.691 | 0.9852 |

### 3.3 判读

**这不是噪声，是机制，且两个对照组都印证了它：**

1. **单调的时间衰减**：越靠近今天，两口径越接近（2020 年 p50=0.874 → 2026 年 1.005）。
   完全符合 qfq「锚定今天」的定义——历史越长，被后续除权除息折算得越多。
2. **送转组失真最重**：p5 比值 0.235，即**失真 4 倍**；排序相关掉到 0.862。
3. **无送转组也失真**（比值 0.883）—— 那是 **6 年现金分红累计 ≈12%** 的折算。
   ⇒ **分红也会污染 PE**，不只是送转。

PE 是线上选股 **60% 的权重**，排序错就是选股错。**必须修。**

### 3.4 修法与影响面

**修法**：PE 改用不复权价 —— `quant/data/universe_pit.load_raw_close()`（`amount/volume`），
在传面板给 `pit_pe_roe_panels()` 前替换掉 qfq 价。已在函数 docstring 里写明这条硬约束。

**为什么这是对的口径**：在任意时刻 t，市场价格与当时已披露的 EPS **本来就是同一个股本口径**，
两者相除天然自洽（送转前后都自洽）。qfq 价则被折到今天，与当时的 EPS 不同口径。

**影响面（重要）**：

- ✅ **线上选股不受影响**。`selector._fetch_pe()` 用的是百度估值接口的 PE(TTM) **当日值**
  （[quant/data/selector.py:87-95](../quant/data/selector.py#L87-L95)），不是 `qfq价/EPS`；
  而且 qfq 在「今天」无折算差。**线上代码一行不用改。**
- ⚠️ **只影响历史回测**。这是新面板独有的坑，且修正发生在任何回测**使用**它之前。
- ℹ️ ROE 不受影响（比值，不含价格项）；BPS 也不受影响（存量，不含价格项）。

### 3.5 残留误差（已知，声明在此）

`amount/volume` 是当日**成交均价（VWAP）**，不是收盘价 —— 相对收盘价有 ±3% 噪声
（实测 p1=0.97 / p99=1.04）。相对于它修正掉的 **最高 4 倍** 失真，这个噪声小两个数量级，
且近似无偏（p50=1.01）。可接受。

若日后要消掉这 ±3%：可重取 `adjust=""` 的收盘价落库（5218 只 ≈ 2 小时），或用
`close_qfq / rolling_median(close_qfq / raw_vwap, 21)` 反推复权因子再做平滑。
**当前不做**，因为收益远小于成本。

## 4. 已知局限（不要当成完备）

| 局限 | 说明 |
|---|---|
| **没有历史 ST 标记** | 无历史 ST 名单，PIT 宇宙未做 ST 过滤 |
| **ROE 去累计是近似** | 累计 ROE 各期分母（平均净资产）不同，逐季相减不是严格定义；但 4 期求和**伸缩相消**后 ≈ 年化 ROE。恒等式校验（§2.1）说明误差很小 |
| **EPS 不追溯重述** | 数据源给的是 as-reported 值。这正是 §3 修正的前提，也是为什么必须用不复权价 |
| **无 2019 年之前的报告** | 报告期从 2019-03-31 起，故 PIT PE/ROE 面板实际只能从 **2020-04-30**（2019 年报可见）开始 |
| **退市股财务数据缺失** | 与行情同源问题，无法补（详见 pit-universe 篇） |
