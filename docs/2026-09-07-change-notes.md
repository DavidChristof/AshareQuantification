# 2026-09-07 改动说明（止损/止盈线按板块涨跌停封顶）

> 按「每次大改动在 docs/ 下留一篇 markdown」约定记录。涉及提交均已合入 main。

## 背景：部分止损/止盈线超出 A股涨跌停幅

**现象**：手动盘持仓卡片上，部分股票的止损/止盈线比例超过了该股板块一天的涨跌停幅（主板 ±10%）。以 09-07 盘中真实持仓为例：

| 持仓 | 板块 | 改动前止损 | 改动前止盈 | 问题 |
|---|---|---|---|---|
| 天赐材料 | 主板 ±10% | −10.0% | **+14.0%** | 止盈超 |
| 东鹏饮料 | 主板 ±10% | −7.3% | **+10.2%** | 止盈微超 |
| 德业股份 | 主板 ±10% | **−12.4%** | **+17.4%** | 双超 |

**根因**：ATR 动态止盈止损（`quant/risk/volatility.py:dynamic_pcts`）的上下限是**不看板块的全局值**（止损 ≤15%、止盈 ≤30%），而 A股按板块限幅是 主板 ±10% / 创业板·科创板(30/68) ±20%。代码里其实已有按板块判涨跌幅的 `quant/trading/rules.py:limit_pct()`，但只用于「委托价校验」（下单拒绝涨停/跌停价），**没用于止盈止损线的设定**。

**为什么超限是不合理的**（不是“反正多日持有能到”这么简单）：

1. **止盈超过涨停幅** → 当天价格最多到 +10%（涨停封板），+14%/+17% 的委托在当天**无标的可成交**，只能死等多日累计涨幅够了才卖——而那时往往已是连续涨停后的高位。纸面盘能“在涨停价成交”，实盘排队未必成交。
2. **止损低于跌停幅** → 假止损。跌停当天价格最多到 −10%，−12.4% 的止损**当天不会触发**，要等次日累计跌破 12.4% 才卖——实际亏损已被跌停天然延后放大（两天连板跌停 ≈ −19% 才出），线给的那句“最多亏 12.4%”是假的。

## 改动：消费侧按个股板块限幅封顶

在**真正触发止盈止损的撮合层**与**卡片显示层**两处，算出止损/止盈/移动止损百分比后，再按该股板块限幅钳制（动态与固定回退都适用）：

```python
band = limit_pct(symbol)          # 主板 0.10 / 创业·科创 0.20
sl  = min(sl,  band)
tp  = min(tp,  band)
if tp <= sl:                      # 高波动被钳到同一顶 → 止损留 5% 缓冲，保证止盈>止损
    sl = band * 0.95
if trail is not None:
    trail = min(trail, band)
```

- **撮合层** `quant/trading/paper.py:apply_stop_rules`：手动盘与自动纸面盘（`updater.py` 共用同一 `PaperBroker`）的真实触发逻辑。
- **显示层** `api/main.py:_position_risk`：持仓卡片的止损/止盈位/百分比——与撮合层同口径，避免“卡片显示一条、实际触发另一条”。

`dynamic_pcts` 本身保持板块无关（纯 ATR 数学，单测不动）；封顶收敛到使用方，且固定 8%/15% 回退（止盈 15% 同样超主板 ±10%）也被覆盖。

## 涉及文件

| 文件 | 改动 |
|---|---|
| `quant/trading/paper.py` | `apply_stop_rules` 内对每只持仓的 sl/tp/trail 按 `limit_pct(symbol)` 钳制 |
| `api/main.py` | `_position_risk` 返回前同口径钳制，卡片显示与实际触发一致 |
| `tests/test_bracket_limit.py` | 新增：主板高波动封顶到 ±10% / 创科允许到 ±20% / 固定回退 15% 止盈压到 +10% |
| `tests/test_volatility.py` | 移动止损用例适配新语义（止盈钳到 +10% 后“先涨 12%”会先止盈，改用涨到 +9%） |

## 备注

- 回测模拟器（`quant/backtest/engine.py` 的逐票日线回测）未加板块钳制：它按**日收盘**撮合、跨多日累计可到线，属离线参考，与纸面实时触发口径的差异已记录在案。若需回测与实盘完全对齐，可后续给 `BacktestEngine.run` 传入 symbol 后补同样的钳制。
