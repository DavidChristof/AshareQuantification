# 2026-09-08 改动说明：开盘前（集合竞价）当日收益归零

> 按「每次大改动在 docs/ 下留说明」的约定。已合入 main。

## 问题

周二早盘未开盘（09:15–09:30 集合竞价），dashboard「当日收益」却显示 −¥18 之类非零值。
根因：实时源（sina）在竞价期返回**竞价撮合价**（time=今日、price 已非 0），
`_live_prices` 用它估值 → 持仓市值相对昨收基准出现小幅漂移 → 被当作“当日收益”。

与 09-04 修的“周六假当日收益”同源：那一次只处理了「非交易日归零」，
漏了「交易日但**还没开盘**」——竞价价不是真实成交，不该算当日盈亏。

## 改动

- `quant/trading/paper.py:live_summary`：新增 `session_started` 参数（默认 True 保持兼容）。
  当日收益改为在 **trading_today 且 session_started** 时才实时计；否则基准对齐当前 → 当日收益 0。
- `api/main.py:manual_account`：按当前时间 `>= 09:30` 传 `session_started`；
  连续交易开始后自动恢复真实当日收益，收盘后（晚间）仍显示当日全天收益，午休不受影响。

## 验证

- 09:25（集合竞价、未开盘）`GET /api/manual/account` → `day_pnl=0.0, day_return=0.0`（基准=当前权益）。
- 回归：`tests/test_engine_hold.py`、`test_calendar.py`、`test_bracket_limit.py`、`test_volatility.py` 全 PASS。
- 开盘(09:30)后自动恢复实时当日收益（逻辑未变，仅加时段门）。

## 二、止损线校准：改“当日收盘触发” + ATR 倍数 2.5→3.0（缓解高频震出）

**背景/实证**：当前持仓多为 60日反转/低波选出的高波动周期股（铝业系）。回放近 130 日，
按现成本+现止损，中国铝业/云铝各被扫 **20/22 次**，打损后 10 日均收益 **+7.3%/+5.6%**
（反弹 85%/73%）→ 紧止损反复把“低波动/反转”逻辑的票震出再踏空反弹。多数线其实是
2.5×ATR（行业常规），问题在：① 盘中插针即触发（实时价每 10s 查，策略是日频）；
② 德业等被 ±10% 板块封顶压到 ~1.9×ATR，相对其波动偏紧。

**改动**：
- `api/main.py:_apply_manual_stops`：止损/止盈/移动止损改按 **SIGNALS 当日收盘价** 触发
  （一天最多在收盘数据刷新后触发一次），盘中插针不再算打损；与日频策略一致。
- `config/config.yaml: risk.atr_stop_mult 2.5 → 3.0`（止损 = 成本 − 3×ATR）。
- `apply_stop_rules` 本体、自动纸面盘(updater 收盘路径)、显示层 `_position_risk` 不变
  （它们本就按收盘/从配置读 3.0），只是手动盘喂价口径改为收盘价。

**实测新线**：分众 3.0×、中国铝业/云铝 ~3.0×（9.7-9.8%），德业仍 1.9×（主板 ±10% 封顶内给不到
3×ATR → 高波动主板票用日线止损必然偏紧的固有上限；如需再松只能超板幅/多日或换票）。
回归测试全过。

## 三、止盈改保守：盘中锁盈 + 目标降到 ~2.5×ATR（≈+6~8%）

**口径**（用户选“盘中锁盈 + 目标≈+7%”）：止盈与止损分开——
- **止盈**：用**实时价**盘中触发（强势日冲到目标即落袋，不等收盘回落）；
- **止损/移动止损**：仍**收盘触发**（上一节口径）。

**改动**：
- `config/config.yaml`：`atr_take_mult 3.5→2.5`（止盈≈成本+2.5×ATR）；固定回退 `take_profit_pct 0.15→0.08`。
- `quant/trading/paper.py:apply_stop_rules`：新增 `apply_stop/apply_take` 开关（默认都开，自动盘/回测不变），
  支持“止盈盘中、止损收盘”的分开调用。
- `quant/risk/volatility.py`：删除 `take_pct ≤ stop_pct → take=1.5×stop` 的 guard —— 止损(向下)/止盈(向上)
  分属价格两侧，**允许 take ≤ stop**（否则保守的 stop_mult 3.0 > take_mult 2.5 会把止盈又顶回板幅 +10%、
  并把止损压回 9.5%，两败）。
- `api/main.py:_apply_manual_stops`：改为两趟调用（①实时价·止盈盘中；②收盘价·止损收盘）。

**实测**：分众止盈 6.1%、中国铝业/云铝 8.1%（≈2.5×ATR，均 < 各自止损 7.3/9.7% → 先锁盈再谈止损）；
天赐/德业因高 ATR 被 ±10% 板幅封顶仍 ~10%。
回归测试全过（新增 `test_separate_stop_take_flags`）。

## 四、当日"止盈/止损自动卖出"记牌 → 组合当日不再重买（防锁盈后又被请回）

**背景**：手动盘止盈/止损是**自动整仓卖出**（前端每 15s 轮询 account/positions 触发，
触发即 `apply_stop_rules→sell`，成交价≈触发时价），**不经过组合调仓**。若刚止盈卖出的票仍
在今日选股 12 只里，组合调仓会把资金再买回去 → 白锁盈还多付手续费。

**改动**（`api/main.py`）：
- `_mark_risk_sold / _risk_sold_today`：风控卖出当天写 `logs/risk_sold_<YYYY-MM-DD>.json`（按日分文件，次日自然失效）。
- `_apply_manual_stops` 两趟触发卖出后统一记牌。
- `_portfolio_from_selection` 顺位补买循环跳过「今日已风控卖出」的代码（已持有的保留逻辑不变）。
- 自动卖出的**留痕**无需额外做：成交记录 remark 本就带"止盈：现价…/止损：…"，前端成交表已显示。

**效果**：止盈/止损落袋的那一天，组合不会把同一只买回来；次日该票若仍在选股 12 里可正常再买。
回归测试全过（helper 往返已验证）。

## 五、开盘自动执行一键调仓（启用 + 用开盘参考价成交，防手动错过/追价）

**背景**：手动盘中点"一键调仓"会错过/追开盘行情。机制 `auto_open_execute` 本就存在（默认关），
现**启用**：服务在 9:31 前后运行 → 自动执行一次 `portfolio_apply`（卖掉落榜 + 按资金买入），日志防同日重复。

**计价口径**（新增 `force_open_ref`）：自动开盘调仓一律按 **昨收 ×(1+open_premium_pct 0.5%)** 成交，
贴近开盘价/回测口径，避免 9:31 用实时价跳空追高；`exec_mode` 仍为 `live` → **手动盘中一键**照旧
实时价 + 追高拦截（不被锁死在开盘窗口内）。

**改动**：`config portfolio_risk.auto_open_execute.enabled: true`；
`api portfolio_apply(force_open_ref)` + `_auto_open_execute_worker` 调用传 `True`。
**注意**：明早(下一个交易日)若服务在 9:31 挂着，会用开盘参考价自动调仓一次——这是有现金/持仓变化的真实操作。
