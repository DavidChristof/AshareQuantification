# 2026-09-07 实验 · 阶段一：构建 600 池日线库 + 40vs600 因子 IC 对比

> 目的：为「把短期模型(v2 集成)从 40 池扩到大横截面训练」做数据与可行性验证。
> 结论先行：**值得扩池** —— 40 池上 |IC|≥0.03 的因子几乎没有（h5 0/34、h20 1/34），
> 扩到 ~600 池后暴涨到 **h5 17/34、h20 21/34**。下一步可进入阶段二（600 池重训 + 留出集验证）。

## 背景

v2 短期模型训练在 40 只大盘池 → 横截面 RankIC≈0。仓库此前怀疑瓶颈是「横截面太窄 / 风格同质」
（scripts/21 诊断原话）。今日选股已用 ~600 池（现池40 ∪ 中证500/1000 中小盘）且因子 IC 实证更好，
但 **v2 模型本身仍只训在 40 池**，与决策池错配。本阶段先把 ~560 只中小盘全历史日线**持久化**，
并同口径算「现池40 vs 大池600」的单因子 RankIC，判断扩池是否值得。

## 对比结果（RankIC，截面秩相关，h=5 / h=20）

| 指标 | 现池 40 | 大池 ~600 |
|---|---|---|
| h=5 · \|IC\|≥0.03 因子数 | 0 / 34 | **17 / 34** |
| h=20 · \|IC\|≥0.03 因子数 | 1 / 34 | **21 / 34** |

600 池上最强的因子（40 池里同因子 ≈0）：
- **低波**：h20 `vol_20` IC **−0.063**（ICIR −0.28）、`vol_ret_20` −0.064；h5 `vol_ret_20` −0.051
- **60日反转**：h20 `rev60` IC **+0.053**（ICIR 0.29）、h5 +0.040；`mom60/mom_20/log_ret_20` 同族同步
- 方向与选股已启用的 regime 技术权重一致（下跌市：低波 + 反转），互相印证

判据（沿用 scripts/21 的决策规则：大池 \|IC\| 明显 ≥0.03 → 值得扩池）：**通过**。

## 说明与局限

1. 这里是**单因子截面 IC**，不等于端到端模型 RankIC；扩池让「可学习的信息密度」明显上升，
   仍需阶段二：v2 在 600 池上重训并做**留出集/时点外 RankIC** 对比，才能定是否切换。
2. 559 只是「有历史行情且成功下载」的子集；个别科创/北交所/停牌失败已跳过（log 可见）。
3. 中小盘含 ST/流动性差个股，重训前需做**剔除 ST、最低成交额、上市时长**过滤（阶段二处理）。
4. 截面基准变了：600 池"跑赢中位数"比 40 池难，模型概率的解读口径随之一致。
